How these numbers are calculated

Tokens: owned request usage from local session logs; copied fork/subagent history is excluded. Chat rows include descendants. Open a chat for its own usage and agent breakdown. Database token totals are shown separately when available because they can include inherited context.

API equivalent: an estimate in USD using the rate for each recorded model, cached input and output tokens. Reasoning tokens are already included in output. Current standard rates apply to historical requests; this is not your subscription bill. Long-context rates are applied per request where supported. Legacy cumulative deltas can span several requests, making long-context estimates less precise. Tool fees, regional surcharges are excluded. Selected/requested Fast tiers use supported Fast rates, including when fallback delivery cannot be verified. Missing speed tiers use Standard by default or the explicitly selected Fast scenario. Daybreak Blue uses a Sol fallback: GPT-5.6 Sol before 22 September 2026 UTC, GPT-6 Sol afterward, never GPT-6.1 Sol. Unknown model rates remain unpriced until you enter them.

Weekly %: the account meter is the latest recorded 7-day limit snapshot, with its observation time and reset time. Per-chat values allocate that meter by each chat’s observed token share in the same window. These are estimates: model weights, usage on other devices, and server-side quota accounting are unavailable. Percentages can lag until Codex records another usage event. Expired snapshots are marked stale.

Timing: current turn elapsed time and accumulated turn wall time. Parallel agent durations are separate. Old unfinished turns with no activity for 15 minutes show “Unconfirmed”; they are not counted as running. Local records cover this Codex home, including archived chats; cloud/remote chats without local records are unavailable.
